# Software Interview Handbook

A phone-friendly static reader for system design, SOLID principle, and design pattern interview notes in `data/`.

## GitHub Pages

1. Push this folder to a GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The published site will update whenever changes are pushed to `main`.

## Preview locally

The site loads Markdown with `fetch`, so it should be served rather than opened directly as a file. Any simple static web server will work.
